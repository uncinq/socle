{{- /* Emits, once per page, the custom properties the previews resolve against, plus the styling of the reference table itself. The token declarations are inlined rather than linked. Each generated file declares its own @layer tokens and contains no @import, so concatenating the leaf files is enough; the barrels (index.css, primitive.css, semantic.css) are the only files with @import and the glob below excludes them by depth. The declarations are moved from :root onto the swatches. The site's own stylesheet already loads these packages, then overrides them with its theme and its dark palette; left on :root, this block would come later in the same layer and undo those overrides across the whole page. Scoped to the content of .t-preview, a swatch shows the package value, the one its row documents, while the table around it keeps the site's colours. The swatches that draw with the text colour (bars, lines, icons) read it from --sw-ink, set on .tokens: a custom property inherits its computed value, so it carries the site's text colour into the swatch, where --color-text holds the package one. */ -}} {{- if not (.Store.Get "tokensStyleEmitted") -}} {{- $leaves := resources.Match "tokens/*/css/*/*.css" -}} {{- $tokens := "" -}} {{- range $leaves }}{{ $tokens = printf "%s\n%s" $tokens .Content }}{{ end -}} {{- $tokens = replace $tokens ":root" ".t-preview > *" -}} {{- $css := $tokens | resources.FromString "css/tokens-inlined.css" | minify -}} {{- .Store.Set "tokensStyleEmitted" true -}} {{- end -}}
